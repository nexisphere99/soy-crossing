## GENERATION NOTES

- All portraits should be consistent across the game   same style, same lighting approach, same level of detail
- Location images should work as backgrounds behind text   avoid high-contrast details in center frame
- All images should match the game's warm-dark aesthetic: `--bg-deep: #0C0A09` through `--accent: #D97706`
- Portraits should be cropped head-and-shoulders, slightly off-center, with negative space on one side for dialogue text
- Use consistent aspect ratios: 16:9 for locations, 3:4 for portraits, 1:1 for UI elements
- No text in images except UI mockups
- Avoid photorealism   aim for illustrated/painterly style that matches the literary tone
